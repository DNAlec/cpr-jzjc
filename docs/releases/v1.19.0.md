# v1.19.0 — 适配 CPR 3.43.0

- 宿主版本：`>=3.43.0,<3.44.0`。
- SDK 与官方打包工具固定至 CPR v3.43.0（`402bc37fbb5c83378cc83cec89e9fa251e4a99c1`）。
- 核对 v3.42.0 → v3.43.0：Rust SDK、插件运行时生产代码及官方 CLI 未变化；新增的前端 `openExternal` 桥接能力不影响本插件现有管理请求。
- 继续使用 RPC v7、管理能力 v2、180 秒维护预算和 `/api/admin/operations/errors`；检测请求仍绑定所选账户。
- 私有状态 schema 保持兼容，同实例升级保留配置、计划、检测历史及指纹库。

## 安装与升级

下载 `personal.modeltrace-health-1.19.0-x86_64-unknown-linux-gnu.tar.gz`，在 CPR 插件管理中上传并切换现有实例。要求 Linux x86_64、glibc 2.36+，已内置 Python/NumPy 评分运行时。

校验文件为同名 `.sha256`。验证结果与范围见 [验证记录](https://github.com/DNAlec/cpr-jzjc/blob/v1.19.0/docs/verification.md)。
